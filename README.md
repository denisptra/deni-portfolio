# Deni Trio Saputra — Portfolio

Interactive portfolio with click-to-find panda puzzle, bilingual toggle, animated starfield, and cinematic intro.

## Tech Stack

- Next.js 16 (Turbopack)
- TypeScript
- Tailwind CSS v4
- Canvas 2D (puzzle + starfield)

## Features

- Click-to-find panda puzzle with 45 interactive objects
- Bilingual EN/ID toggle
- Animated starfield with meteors
- Custom 404 page with panda
- Page transitions
- Bamboo collectibles across pages
- Panda guide ("Po") with Secret Room
